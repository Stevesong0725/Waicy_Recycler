# 지식 자료 (AI가 답변 근거로 쓰는 문서)

- `national.md` — 전국 공통 분리배출 기준. 모든 질문에 사용됩니다.
- `regions/<지역id>.md` — 구별 배출 안내. 지역 id는 `shared/regions.ts` 참고 (예: `gangnam`, `songpa`).
  파일이 없는 지역을 선택하면 전국 기준으로 답하고, 지역 정보는 "구청 확인"으로 안내합니다.

## 작성 원칙
1. **공식 출처만** 사용하고, 파일 맨 위에 출처 URL과 확인일을 적어주세요.
2. 확인하지 못한 항목은 `미확인`으로 두세요. AI는 미확인 항목을 지어내지 않도록 지시받습니다.
3. 수정 후 서버를 다시 띄우면(로컬) / 다시 배포하면(Vercel) 반영됩니다.

## 새 지역 추가
1. `regions/gangnam.md` 를 복사해 `regions/<id>.md` 로 저장
2. `shared/regions.ts` 에 해당 지역이 없다면 추가
